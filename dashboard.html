      Notifications

      When an agent needs approval, the gateway can ping you on your phone and in Slack. Each message has a secure one-tap link to approve or reject that one action; the link stops working once it's decided.

      Rules

      What agents may do is decided by rules.yaml on the gateway: allow, block, or hold for a person (optionally a specific role). Edits apply within seconds. Use Test a rule to check what would happen.

      Approve from your phone

      Scan with your phone's camera. It opens your approvals inbox, signed in as . Anyone who scans this can act as you, so don't share it.

      No public address is set, so this only works on the same Wi-Fi/PC. An admin can set it in Settings.

      For instant pop-ups, also turn on phone notifications in Settings.

      Stop agents?

      Every action any agent tries will be blocked immediately, until an admin resumes them. Actions already running aren't interrupted.

      Approval queue shortcuts

      jSelect the next waiting request (nothing is selected until you choose)
      kPrevious waiting request
      aApprove the selected request: press a twice within 3 seconds
      rReject: focus the note field, then press Enter to reject (Esc to cancel)

      Gateway API key

      Paste your key (it starts with gw_). The admin key was printed when the server first started; anyone with access to the server can make a new one with python server.py add-key NAME --approver. It's kept in this browser only.
