Squidbrake

Agents propose. People approve.

Squidbrake checks what your AI coding agents do before it happens. Everyday work runs on its own; what can't be undone (force pushes, deletes, destructive SQL, cloud deletes) waits for a person.

Install

One line. It installs Squidbrake, connects the agents on this computer and opens the dashboard.

  • Works with Claude Code, Cursor, Codex, Gemini CLI, VS Code and Antigravity.
  • Runs on your computer. The first time, it asks whether to send anonymous usage stats; you can say no.

Open source: github.com/batrapulkit/squidbrake. Setting it up for a team? Tell us about it.
