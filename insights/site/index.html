Every step looks fine. The chain doesn't.

AI agents can now touch cloud, production and payments. Each action they take looks fine on its own, but a chain of fine actions can add up to something nobody authorized, like deleting a production database.

Squidbrake watches the whole chain and stops the step that makes the combination dangerous.

      Questions security teams ask first

      Does any of our data leave our network?

      No. Squidbrake runs where you run it, on a laptop or in your cloud. Tool calls, results and the audit log stay in your database.

      Does it use an LLM to decide?

      No. Decisions come from your rules, a command parser and the agent's recent history. The same call gets the same answer every time, and every answer names the rule that made it.

      What happens if Squidbrake is down?

      You choose. By default a call that can't be checked doesn't run. Set GATEWAY_FAIL_OPEN if you'd rather keep agents moving.

      Can the agent get around it?

      It's built for the common case: a cooperative agent that makes a mistake, or follows instructions it read in an email, a web page or an issue. Everything that goes through a connected tool is checked outside the model, where a prompt can't rewrite it. That includes the agent trying to change its own settings or Squidbrake's rules, which waits for a person. It doesn't see inside a script the agent writes and then runs, or tools you haven't connected. For an agent you don't trust at all, run it in a sandbox too.

      Doesn't auto mode already handle this?

      Keep auto mode for everyday work: it should decide the 99% of steps that are easy to undo. Squidbrake is for the 1% you can't take back, and there the person running the agent shouldn't be the only one saying yes. A teammate approves, with the effect in front of them, and a wrong yes can often be undone.

      How does this help with SOC 2?

      SOC 2's change-management control asks that changes be authorized and approved. Once agents change production, your auditor will ask who approved what they changed. Squidbrake records a second person's approval for every risky step in a tamper-evident log, and the evidence pack puts it on one page. It supports your evidence; your auditor decides what it satisfies.

      Will it slow our agents down?

      The check takes 3.3 ms at the median and 9 ms at p95 on a laptop. A model takes seconds to choose a tool.

      How do we start without breaking anything?

      Turn on shadow mode. For the first week nothing is blocked. You see what would have been, then decide what to enforce.
